붙어볼 만한 상대를 찾아드려요

단톡방에 수소문할 필요 없이, 우리 팀 지역과 실력에 맞는 상대팀을 앱이 먼저 추천해요.

실력이 맞는 경기만 남겨요

전적으로 쌓인 실력 데이터를 기준으로 매칭해, 한쪽이 일방적으로 이기는 경기를 줄여요.

검증된 구장에서 경기해요

제휴 구장의 위치·요금·예약 정보를 앱에서 바로 확인하고, 매칭룸에서 일정까지 한 번에 확정해요.

뛴 만큼 전적으로 남아요

경기가 끝나면 승·무·패가 자동으로 쌓여 팀 프로필이 되고, 지역 랭킹에 그대로 반영돼요.

핵심 기능

우리 팀의 경기를
더 쉽고, 더 재미있게.

01 추천 매칭

해볼 만한 상대를
골라줘요

우리 팀 실력과 지역을 분석해 붙어볼 만한 상대팀을 추천해요.

  • ✓지역·실력 기반 상대팀 추천
  • ✓"예상 승률 63%" 매칭 정보 제공
  • ✓전체 팀 리스트에서 직접 신청
02 매칭룸

매칭이 수락되면
매칭룸에서 확정

전용 매칭룸에서 날짜·장소·시간을 깔끔하게 정해요.

  • ✓매칭 성사 시 전용 채팅방 자동 개설
  • ✓일정·장소·시간 한 곳에서 확정
  • ✓누가 언제 어디서, 헷갈릴 일 없음
03 전적·기록

경기 결과가
전적이 돼요

경기마다 승·무·패가 팀 프로필에 자동으로 쌓여요.

  • ✓승률·연승·최근 전적 자동 기록
  • ✓상대 전적(H2H)까지 한눈에
  • ✓뛸수록 성장하는 우리 팀 데이터
04 지역 랭킹

우리 동네 1등,
누가 될까?

경기할 때마다 지역 랭킹이 실시간으로 바뀌어요.

  • ✓승리 +5 · 무승부 +2 · 패배도 +1점
  • ✓실시간 지역·전국 랭킹
  • ✓시즌 상위 팀엔 보상까지
05 팀장 일괄결제 준비 중

구장비, 팀장이
한 번에 결제

지금은 구장에서 현장 정산해요. 앱에서 바로 결제하는 기능을 준비하고 있어요.

  • ✓현재: 앱에서 예약 요청 → 구장 승인 → 현장 정산
  • ✓준비 중: 팀장 일괄결제로 송금 걷을 필요 없이 한 번에
  • ✓결제 기능 오픈 시점은 앱 공지로 안내드려요
구장

구장 잡는 것까지
앱 안에서 끝나요.

제휴 구장은 앱에서 바로 예약하고, 이미 쓰는 구장이 있으면 직접 입력해서 그대로 경기해요.

제휴 구장 찾기

지도에서 근처 구장을
한눈에

지역과 일정으로 근처 제휴 구장을 찾고, 요금과 시설을 비교해요.

  • ✓지도·목록으로 근처 제휴 구장 탐색
  • ✓실내·실외, 코트 수, 시간당 요금 비교
  • ✓주차·샤워실 등 편의시설까지 확인
코트·시간 예약

날짜와 시간을 고르면
예약 요청 끝

비어 있는 시간대를 눌러 예약을 요청하고, 구장이 승인하면 확정돼요.

  • ✓날짜별 빈 시간대를 눌러서 바로 선택
  • ✓연속된 시간대는 원하는 만큼 이어서 예약
  • ✓구장 승인 후 확정 · 이용료는 현장 정산
